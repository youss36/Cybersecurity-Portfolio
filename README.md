# Botium Toys - Internal Security Audit & Risk Assessment

## 📋 Project Overview
This project is part of the Google Cybersecurity Professional Certificate. It involves conducting a comprehensive internal security audit for **Botium Toys**, a growing toy retailer expanding into international e-commerce markets.

## 🔍 Scope & Objectives
- **Scope:** Evaluated the entire security program, IT-managed assets, physical security, and internal procedures[cite: 7].
- **Objectives:** Assess current security posture, identify vulnerabilities, evaluate physical, technical, and administrative controls, and ensure regulatory compliance (PCI-DSS, GDPR, SOC).

## ⚠️ Risk Assessment Summary
- **Risk Score:** 8/10 (High risk due to missing security controls and compliance gaps)[cite: 7].
- **Key Vulnerabilities / Findings:**
  - Lack of data encryption for credit card transactions and customer data stored locally[cite: 7].
  - Absence of **Least Privilege** and **Separation of Duties** (all employees currently have access to internal stored data)[cite: 7].
  - No Disaster Recovery plans or automated backups of critical data[cite: 7].
  - Missing Intrusion Detection System (IDS)[cite: 7].
- **Existing Controls:** A properly configured firewall, active antivirus software, physical locks, CCTV surveillance, and fire prevention systems are in place[cite: 7].

## 🛠️ Security Controls Assessed
The controls evaluated are divided into three main categories[cite: 6]:
1. **Administrative Controls:** Password policies, access control policies, and separation of duties[cite: 5, 6].
2. **Technical Controls:** Firewalls, encryption, antivirus, and backups[cite: 5, 6].
3. **Physical Controls:** Office/warehouse locks, CCTV surveillance, and fire alarms[cite: 5, 6].
